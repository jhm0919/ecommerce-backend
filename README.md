## ecommerce-backend

## 코드 컨벤션
- 클래스명은 **PascalCase**를 사용한다. (예: MainActivity)
- 변수명 및 메서드명은 **camelCase**를 사용한다. (예: findShade())
- 상수는 **UPPER_SNAKE_CASE**를 사용한다. (예: MAX_DISTANCE)
- 들여쓰기는 스페이스 4칸을 사용한다.

## 커밋 규칙
- feat: 새로운 기능 추가
- fix: 버그 수정
- docs: 문서 수정
- style: 코드 포맷팅, 세미콜론 누락, 코드 변경이 없는 경우

## 브랜치 전략
- main: 배포 가능한 상태만을 관리하는 브랜치
- develop: 다음 출시 버전을 개발하는 브랜치
- Feature/기능명: 기능을 개발하는 브랜치

## 개발 환경
- Language: Java 17
- IDE: IntelliJ
- Build Tool: Gradle-Kotlin
- Framework: Spring Boot 4.0.5
- Database: MySQL 8.0.41
